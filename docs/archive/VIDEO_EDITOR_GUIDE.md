# 🎬 Video Editor Guide

## Overview
The Video Editor is a powerful 4K layered video composition tool that lets you create professional multi-layer video compositions with precise control over positioning, scaling, and layering.

---

## Getting Started

### Opening the Video Editor
1. From the main Paint screen, tap the **Projects** button (💾)
2. In Projects Overview, tap **🎥 Video Storage**
3. In Video Storage, tap **🎬 Video Editor** in the top-right corner

### First Time Setup
When you first open the Video Editor, you'll see an empty 4K canvas (3840×2160). Before you can start composing:
1. Import videos into Video Storage first
2. Videos can be:
   - Exported timelapses from your emoji paintings
   - Imported from your device camera roll
   - Screen recordings you've created

## Interface Layout

### Top Section
- **🔓/🔒 Lock Button** (Top-Left, Large)
  - **Unlocked** (🔓): You can drag and move video layers on the canvas
  - **Locked** (🔒): Canvas is locked, prevents accidental movements
  - Tap to toggle between locked/unlocked states
  - Shows in **orange** when locked
  - **Large 3x emoji** - no background panel, just the emoji itself

- **Zoom Slider** (Top-Right)
  - Controls the canvas zoom level (8% to 50%)
  - Drag left to zoom out, right to zoom in
  - Helps you see the full composition or focus on details
  - Works independently of layer scaling
  - **Half-width** panel for compact design
  - Label shows "ZOOM"

### Middle Section
- **Scale Slider** (Middle-Right)
  - Only appears when a video layer is selected
  - Controls the size of the selected video layer (10% to 500%)
  - Drag left to shrink, right to enlarge
  - Each layer has its own independent scale
  - **Half-width** panel positioned on right side
  - Label shows "SCALE"

### Bottom Section
- **📋 Layers Button** (Bottom-Left)
  - Shows number of layers in parentheses
  - Tap to open the layer management panel
  - Reorder layers by dragging
  - Delete layers with the trash icon

- **+ Add Video Button** (Bottom-Left)
  - Tap to add a new video layer to your composition
  - Opens video picker showing all available videos
  - Videos are added at canvas center

- **Layer Filmstrip** (Bottom)
  - Shows thumbnails of all layers
  - Tap a thumbnail to select that layer
  - Selected layer has an **orange border**
  - Non-selected layers have white borders

## Working with Layers

### Adding a Video Layer
1. Tap the **+** button at bottom-left
2. Select a video from the picker
3. Video appears in the center of the canvas
4. New layer is automatically selected (orange border)

### Selecting a Layer
- **Method 1**: Tap the video on the canvas
- **Method 2**: Tap the layer's thumbnail in the filmstrip
- Selected layer gets an orange border and shows scale slider

### Moving a Layer
1. Unlock the canvas (tap 🔓/🔒 button until it shows 🔓)
2. Select the layer you want to move
3. Drag the video to desired position
4. Position is precisely tracked on the 4K canvas

### Scaling a Layer
1. Select the layer (orange border)
2. Use the **Scale slider** that appears
3. Drag left (shrink) or right (enlarge)
4. Scale range: 10% (tiny) to 500% (huge)

### Layer Order (Z-Index)
1. Tap the **📋 Layers** button
2. Drag layers up/down to reorder
3. Top of list = front of composition
4. Bottom of list = back of composition
5. Layers overlap based on their order

### Deleting a Layer
1. Tap **📋 Layers** to open layer panel
2. Find the layer you want to remove
3. Tap the **🗑️** trash icon next to the layer
4. Confirm deletion

## Projects & Saving

### Saving Your Work
1. Tap the **💾 Save** button (top-center)
2. Enter a project name
3. Project is saved with a video thumbnail
4. Auto-save happens when you leave the editor

### Loading a Project
1. Tap the **💿 Projects** button (top-center, animated cycling emoji)
2. See all saved projects with video preview thumbnails
3. Tap a project to load it
4. All layers, positions, and scales are restored exactly as saved

### Project Overview Features
- **Video Preview Thumbnails**: Each project shows a snapshot
- **Project Name**: Displays the name you gave it
- **Timestamp**: Shows when it was last saved
- **Delete**: Long-press a project to delete it (confirmation required)

## Exporting Your Composition

### Export to Video File
1. Tap the **📹 Export** button (top-right)
2. Choose export format:
   - **MP4**: Standard format, smaller file size, no transparency
   - **MOV**: ProRes 4444, larger file size, preserves transparency
3. Wait for export progress (shows percentage)
4. Video is rendered in full 4K resolution (3840×2160)
5. Once complete, video is saved to Video Storage
6. You can then share it from Video Storage

### Export Progress
- Shows real-time progress percentage
- Displays current status (Processing layers, Rendering composition, etc.)
- Canvas preview shows what's being exported
- **Do not close the app during export**

### Export Quality
- **4K Resolution**: All exports are 3840×2160 pixels
- **Frame Rate**: Matches the longest video layer's frame rate
- **Duration**: Composition length equals the longest video layer
- **ProRes 4444** (MOV): Preserves alpha transparency, highest quality
- **MPEG-4** (MP4): Good quality, smaller files, no transparency

## Tips & Best Practices

### Composition Tips
1. **Start with Background**: Add your background layer first
2. **Layer Order Matters**: Arrange from back to front
3. **Use Zoom**: Zoom out (8%) to see the full composition
4. **Lock When Done**: Lock canvas to prevent accidental moves
5. **Save Often**: Projects auto-save, but manual saves are instant

### Performance Tips
1. **Limit Layers**: 3-5 layers usually works best
2. **Preview Before Export**: Make sure everything looks right
3. **Close Other Apps**: Free up memory for smooth editing
4. **Shorter Videos**: Longer videos take more time to export

### Layout Workflow
1. **Unlock** the canvas
2. **Zoom out** to see full canvas
3. **Add all videos** you need
4. **Position** each layer where you want it
5. **Adjust scale** for each layer
6. **Reorder layers** in the layer panel
7. **Lock** the canvas
8. **Preview** the result
9. **Export** when ready

### Common Mistakes to Avoid
- ❌ Forgetting to unlock canvas before trying to move layers
- ❌ Not selecting the right layer before scaling
- ❌ Exporting before checking layer order
- ❌ Closing app during export
- ❌ Not saving project before exiting

## Troubleshooting

### "No Videos" Error
- **Problem**: Can't add videos to canvas
- **Solution**: Go to Video Storage and import/export videos first

### Layer Won't Move
- **Problem**: Can't drag a layer
- **Solution**: Check if canvas is locked (🔒). Tap to unlock (🔓)

### Can't Find Scale Slider
- **Problem**: Scale slider not visible
- **Solution**: Select a layer first (tap on video or thumbnail)

### Export Failed
- **Problem**: Export stops or crashes
- **Solution**:
  - Close other apps to free memory
  - Try shorter videos or fewer layers
  - Restart the app and try again

### Project Won't Load
- **Problem**: Tapping a project doesn't load it
- **Solution**:
  - Make sure all videos from the project still exist in Video Storage
  - If videos were deleted, the project can't load

### Layers Disappear
- **Problem**: Added layer not visible
- **Solution**:
  - Check if it's behind another layer (use layer panel to reorder)
  - Zoom out to see if it's off-screen
  - Check if layer is extremely small (scale slider)

## Advanced Features

### Multi-Layer Effects
- **Picture-in-Picture**: Small video in corner of larger video
- **Split Screen**: Two videos side by side (scale to 50%, position left/right)
- **Overlay**: Semi-transparent layer over background
- **Collage**: Multiple small videos arranged in a grid

### Precision Positioning
- The canvas is 3840 pixels wide × 2160 pixels tall
- Each layer tracks exact X,Y coordinates
- Zoom out to see positioning guides
- Use layer panel to see exact position values

### Alpha Transparency
- Export as **MOV (ProRes 4444)** to preserve transparency
- Useful for overlaying videos with transparent backgrounds
- Emoji timelapse videos have transparent backgrounds by default
- Layer blending happens automatically

## Specifications

### Canvas
- **Resolution**: 3840 × 2160 pixels (4K / UHD)
- **Aspect Ratio**: 16:9
- **Color Space**: RGBA (with alpha channel)
- **Coordinate System**: Top-left origin (0,0)

### Zoom Range
- **Minimum**: 8% (see entire canvas)
- **Maximum**: 50% (close-up detail)
- **Default**: ~25% (balanced view)

### Scale Range (Per Layer)
- **Minimum**: 10% (very small)
- **Maximum**: 500% (5x original size)
- **Default**: 100% (original size)

### Export Formats
- **MP4**: H.264/MPEG-4, YUV420p, 8M bitrate
- **MOV**: ProRes 4444, YUVA444p10le, alpha channel support

### Supported Video Formats (Import)
- MP4, MOV, M4V
- H.264, HEVC, ProRes codecs
- Any resolution (will be scaled/positioned on 4K canvas)

## Project File Structure

Projects are saved with:
```json
{
  "id": "unique-project-id",
  "name": "My Composition",
  "timestamp": 1234567890,
  "thumbnail": "base64-encoded-image",
  "layers": [
    {
      "videoId": "video-uuid",
      "x": 960,
      "y": 540,
      "scale": 1.0,
      "zIndex": 0
    }
  ]
}
```

### Storage Locations
- **Projects**: `@video_editor_projects` (AsyncStorage)
- **Active Session**: `@video_editor_active_session` (AsyncStorage)
- **Video Files**: Expo FileSystem cache directory
- **Exports**: Video Storage directory

## FAQ

**Q: How many layers can I add?**
A: Technically unlimited, but 3-5 layers is recommended for best performance.

**Q: Can I use my own videos?**
A: Yes! Import them through Video Storage.

**Q: Does it work offline?**
A: Yes! All editing happens on-device.

**Q: Where are my exports saved?**
A: Exported videos go to Video Storage, accessible from the main app.

**Q: Can I edit the videos themselves?**
A: No, this is a composition tool. You position, scale, and layer videos, but don't trim or edit their content.

**Q: Will my phone get hot during export?**
A: Yes, 4K video rendering is intensive. This is normal.

**Q: How long does export take?**
A: Depends on video length and layers. A 10-second 2-layer comp takes ~30-60 seconds.

**Q: Can I cancel an export?**
A: Currently no, let it complete. Future update may add this feature.

**Q: What if I run out of storage?**
A: Delete old videos/exports from Video Storage, or old projects from Projects Overview.

**Q: Can I share projects with others?**
A: Projects are local only. Share the exported video file instead.
